# 连续变身方法

仅在输入要求连续形态变化时读取。将变化写成可观察的过程，保留初始态、目标态及中间状态，避免用特效遮盖替代本应展示的变化。

## 定义两态与保持项

明确同一主体的初始与目标形态，区分需要保持的身份、空间关系、持物与背景，以及剧情允许变化的站位和朝向。变化只涉及用户指定的属性，不自动更换人物、丢掉道具或冻结原有移动。

已有参考分别绑定两态，按明确的采用范围继承对应部位；多张图片不自动代表时间顺序。正文只补充必要的部位和变化关系，不重复大段外观描述。纯文字任务直接采用已给出的特征，不虚构参考图或强制使用图像指针。

## 组织局部变化

按输入选择覆盖路径或形态过渡方式。只有特效经过某处才触发重构的设定，才采用区域驱动：尚未经过的区域保持初始态，已完成的区域保持目标态，边界经过处连续过渡。全身同时变化或其他明确机制按原要求处理。

自下而上粒子雾带型变身可采用以下完整过程；这是对应类型的配方，不是所有变身的必经路径：

1. **起旋与进入**：雾带从已设定的来源出现，接近双足，建立包裹路径；角色自身不因雾带旋转而自动转身。
2. **下肢重构**：雾带经过双足与下肢时，对应部位逐步成为目标态，上方未经过区域仍保持初始态。
3. **躯干与旧态处理**：变化继续经过腰腹与上身；确需替换的旧衣物或特征连续演变、剥离或消融，方式遵从输入，不无依据消除持有物与配饰。
4. **面容与发饰过渡**：涉及变化的面部、发型及发饰完成连续过渡，不在遮挡结束后直接跳成另一人物。
5. **特效收束与目标态承接**：按设定向上散逸、退去、回收或持续附着，让目标态保留。承接变化完成时的位置、朝向、持物与后续动作，不固定为居中、正面或静止。

## 可选的粒子分层配方

能量粒子雾带需要体积层次且允许发光时，可采用深色吸收核心、中层发光微粒与外缘羽化烟雾交织的结构。具体说明浓淡差异、可见光、柔化边缘与卷动关系，不只写“三相”标签。

配色、发光方式与介质服从输入。用户修改一层时，只替换冲突属性，保留其他相容的层次与连续运动；明确无自发光的效果不要补入发光层。机械展开、液态重塑或其他机制不强制使用粒子、水汽与大理石纹理。

## 过程检查

检查变化是否完整覆盖目标属性，旧态是否按机制得到处理，中间区域是否保持正确状态，特效结束或继续存在后主体是否仍承接目标态。不能仅凭出现“平滑”“重构”或粒子术语判定过程已写清。
