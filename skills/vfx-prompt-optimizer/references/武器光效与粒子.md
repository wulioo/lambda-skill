# 武器光效与粒子

用于在已有特效需求或用户明确授权的范围内，细化武器附光、粒子与覆盖范围。依据已有能力、武器形制、风格、动作和原镜头作选择，保留功能、范围与已锁定外观；效果名称按[主文件的具象化规则](../SKILL.md#明确形态与光学表现)处理，不重编动作或改变拍法。

## 从当前效果选择形貌

先判断光来自刃缘、尖端、纹路、武器内部还是包覆层，再明确适用的光膜、流光、火焰、电弧或其他既定形态，以及颜色、边界和亮度关系。只有发光变化时，无需强加粒子；采用粒子时，先区分其构成主体效果，还是辅助边缘、拖尾或接触散粒，再根据所需观感选择外形、大小、疏密及分布，不把术语当作可见描述。

用户没有指定这些细节时，依据当前任务自主补足能形成辨识度的属性，不要求用户逐项选择；输入已充分时保留，不为写满属性表追加效果。

## 分开确定覆盖范围

- **武器本体覆盖。**说明刃口、刃面、棍身等哪些部位被覆盖，沿长度、局部表面区域还是整件武器分布。按需要交代仍可辨认的材质、边界和握持部位。
- **周围空间延伸。**分别判断附着光层的厚度、粒子散布宽度、拖尾长度或接触喷散范围。用武器长度、刃宽、身体尺度与现有场地作参照，按当前效果选择必要项目。
- **当前画面占比。**它随景别、透视和构图变化，不能代替世界中的尺寸。镜头收近后效果占画面更大，不自动意味着武器效果扩大或攻击距离增加。

需要约略比例时，明确所指是长度、表面覆盖还是画面，例如“自剑尖向后延伸约三分之二刃长”，而不是含义不明的“覆盖三分之二”。视觉范围、攻击范围和伤害分别服从既定设定，视觉拖尾不自动成为脱离武器的远程攻击。

分析参考片时，只记录画面能够支持的形态和相对范围；无法可靠辨认的覆盖比例、粒径或尺寸不写成测量结果。获准补设计时选择的比例属于本方案，不宣称来自原片实测，也不作精确执行保证。

## 让粒子与既有动作配合

从产生位置、主体动势和已知气流判断粒子沿哪里流动、向哪侧脱落，以及怎样拖曳或衰减。挥动、回收和接触可改变分布与强度，持续附着部分仍跟随武器；原动作确有接触时，才细化相应接触喷散，不新增一次碰撞。

按原事件选择必要变化，不统一要求先蓄力、再爆发、最后完全消散。同一效果首次出现时明确稳定外观，后续着重写当前变化，跨镜头继承附着位置和状态。

## 在原镜头中校准表现

连续拆招时，粒子、亮度和轨迹应让攻击与应对获得所需可见性；近景可突出附着边界和粒子层次，宽画面侧重整体轮廓、路径及范围。只补当前镜头能呈现的细节，不为展示粒径重选机位或插入慢动作。

效果大小由既定能力、授权范围和本场目的决定。按需要调整光层边界、透明度、亮度或疏密，不把全部效果统一收成细线，也不用满屏粒子替代作用过程。受光、遮挡和反射按实际位置与原画面相容处理，不因附光而自动照亮全场或增加破坏。
