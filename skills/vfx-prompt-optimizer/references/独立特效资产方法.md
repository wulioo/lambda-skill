# 独立特效资产方法

仅在用户已有目标是独立特效元素、合成资产或特效展示提示词时读取。输出仍为文字，不制作素材或提交生成任务。

## 本体与参考范围

明确需要保留的是效果本体、发射源、附着物还是完整交互画面。“独立特效”不自动意味着无武器、无接触面；无人物、无场景等要求按输入范围执行。

已有参考只承担指定的形态、运动、材质或其他职责，不自动带入参考中的人物与背景。保留原标签与编号，不新增参考或宣称看过不可读取的素材。

## 背景与可见性

沿用指定背景、机位与裁切，保留动作展开和尾迹所需的画面范围。检查效果是否可见：完全纯黑且不反射、不发光的效果在纯黑背景上缺少可见差异；只靠折射表现的效果在均匀背景上也可能无法读到形态。

输入允许选择背景或光学表现时，选择能体现目标效果的对比关系；两者都锁定且无法兼容时，指出具体冲突，不擅自换背景或增加发光描边。

区分画面中的黑底、其他纯色底与透明通道要求。黑底不等于透明 Alpha，不仅凭提示词承诺能得到可直接合成的透明素材。

## 运动与结束状态

写清本体的几何轮廓、空间朝向、附着点或来源、运动方向及必要的边缘变化。无主体入画时，使用已经明确的作用点或运动关系描述，不为解释来源增造人物。

按输入组织形成、持续、推进、回收或消散，保留指定循环与结束状态。需要完整展示时，检查核心和尾迹是否因裁切提前消失；固定镜头不自动增加跟拍、旋转或拉远。

仅在已有声音需求内细化对应事件。背景、参数、画幅与用户原有符号约定保持不变，不自动加入黑底、音效或平台格式。
