# 特效提示词优化

输入现有提示词，判断特效需要让观众看懂什么，把效果写成原镜头能够呈现的形态、运动与变化，输出优化后的完整提示词。

## 优化边界

- 独立完成文字优化，不依赖其他 Skill，不修改参考素材，不调用生成或渲染工具。
- 以用户最新明确要求为准，保留剧情事实、人物与场景设定、对白、关键动作及结果、空间关系、镜头组织与拍法、时间要求、声音、参数及明确锁定的状态。素材引用保留原形式、编号和职责；未读取素材时，不补写依赖素材观察的细节。
- 只在原文已有特效需求或用户明确要求增加特效的范围内补足表现，不自行增加法术、爆炸、伤害、破坏、人物、道具或独立事件。特效名称与功能继续成立，不因具象化而改变世界设定或故事结果。
- 沿用用户指定的写实、动画或其他风格。烟气、液体、火焰、粒子、光学畸变等是可选表现，不把所有特效改成三色雾带、空气激波或胶片实拍质感。

## 优化方法

### 分析剧情与特效作用

先判断特效用于攻击、防御、形态变化、环境事件、信息揭示还是独立展示，找出触发、作用对象及必须读到的结果。检查缺少什么：形态不清、运动无来源、交互缺失、状态突变，或细节遮住关键动作与信息。已有效的表现保留，不为显得壮观增加效果。

结合原镜头的景别、遮挡、时长与叙事重点，明确观众首先需要读到的形态或变化，材质差异、环境反馈与细小粒子按需要辅助。在输入允许的范围内，用相对范围、亮度和清晰度区分主效果与辅助细节，描写篇幅随重要性分配。特效可以参与揭示信息，也可以暂时遮挡，但须遵循既定顺序，不提前展示结果，不为展示微观变化重选机位或插入慢动作。

### 明确形态与光学表现

保留“护盾”“剑气”等名称，先明确整体几何形态、物态及空间关系，再按需要选择内部纹理、边界、颜色与发光、反光、透光或遮光表现。区分发光结构、反光实体与遮光介质，只细化当前效果实际采用的表现。选择决定辨识度的属性，不逐项填写物理参数。术语只辅助表达，不代替可见结果，也不宣称模型执行了真实物理解算。

分别写清效果的空间范围与浓淡，避免将“浓密”写成铺满画面，或将“紧贴”写成稀薄。区分烟气的卷动、扩散与液体的表面反光、黏滞拉丝；“流体”本身不等于液体。不要无依据编造尺寸、透光率或粒径。

大尺度效果优先利用已有环境参照、相对大小、距离与遮挡关系表现尺度；大气透视按环境选择，不强制新增云雾、暴雨或前景人物。检查效果与背景的可见对比，避免同时要求完全纯黑的效果和纯黑背景却不给出可辨认方式。

### 明确运动与环境交互

写清效果从哪里产生、附着或作用于哪里、沿什么路径运动，以及与主体动作的关系。区分紧贴包裹、拖尾和脱离释放，固定附着范围不自动变成大范围爆发。拖尾方向依据主体相对运动与已知气流确定，不随机飘动。

按原事件补足能够看见的遮挡、光照、折射、接触或受力反馈。依据已明确的镜头与素材条件，让效果的透视、尺度、遮挡、景深与运动模糊和原画面相容。需要发光反馈时，依据距离、表面朝向与遮挡关系，说明相关可见表面的受光差异。发光、透光与遮光效果采用相容的交互，不一律点亮环境，也不凭空增加地面开裂或物体损坏。声音按已有需求与发生事件对应；无声任务保持无声，不强制添加声学分层或指定频率。

### 组织变化与跨镜头承接

静态画面只描述当前状态；连续影像再组织生成、持续、变化与结束。阶段按事件需要选择，不强制每种效果先蓄力、再爆发、最后消散；持续、循环或附着效果可以在结束时继续存在。沿用已有时间与同步关系，不编造精确控制承诺。

同一效果跨镜头反复出现时，沿用已有名称与定义；需要补清时，将名称与稳定属性融入首次出现的原段落，后续只补充当前动作、位置与状态变化。切镜不自动重置浓淡、形态或作用对象，剧情允许的变化也不应被全局约束冻结。

连续变身时，读取[连续变身方法](references/连续变身方法.md)，检查初始态、目标态、局部变化路径与状态保持。只有独立特效资产任务才读取[独立特效资产方法](references/独立特效资产方法.md)，处理本体范围、背景可见性与完整运动过程。

当目标为真人影像，且需要细化体积层次、几何场域、近身附着、多效果叠置或画面融合时，读取[真人影像特效表现方法](references/真人影像特效表现方法.md)。只采用与当前效果相关的分支，再回到通用方法完成优化。

## 输出要求

默认只输出一个优化后的完整提示词，沿用原语言、素材引用与符号约定。保留原有标题、段落、空行、缩进、列表与编号；新增描写融入原段落，不另起段、不重排、不套新模板。不附分析或修改说明，不套用平台专用格式或额外参数。没有特效需求或已经充分时，保留原文；指定优化范围时，只处理该范围。

用户要求分析或比较时按请求回答。没有待优化文字时，简短请求提供提示词；缺项按已明确的目标保守补足，不把推测写成已确认事实。明确要求存在无法兼容且会改变核心结果的冲突时，提出一个简短问题，不擅自改动要求。

## 质量检查

- 新增细节有输入依据，特效的名称、作用对象、关键功能与结果保持成立。
- 形态、物态、范围、运动和交互相容，关键变化在原取景与节奏中可读。
- 起点、路径、变化后的状态及必要收束连续，跨镜头没有无依据重置。
- 剧情、对白、镜头、时间、声音、引用及锁定状态得到保留，没有为增加特效而新增事件。
- 输出完整，未堆叠术语、配方或通用负向清单，也未把提示词当作生成质量保证。
