# 真人写实

默认 Seedream 5.0 真人胶片人像的画面与摄影基底，无需用户点名 Seedream 即采用。写实描述材质与光学表现，人物保持用户要求的美感与理想化程度；本文件不提供固定人设。追加 MJ 或 GPT 图像版本时，以同一画面方案进行模型适配。

## 使用方式

- 用户提供完整提示词时采用用户文本；从零设计时，先按主文件对齐关键方向或取得自主设计授权，再将人物方案与下方画面基底整合，不另要求用户指定模型。
- 默认面部特写、暗调夜景与下方双光源关系，不额外指定地点；该基底采用 16:9 画幅，用户已有或新指定的画幅优先。换人物不自动换场景、光影或画幅。
- 人物段使用紧凑但细节充分的关键词，密度按[主文件的人物规则](../SKILL.md#组织可见画面)执行；光影段保留方向、强弱、冷暖与受光结果。冷白发丝勾边描述高光颜色，不将不同人物的发色统一改为银白色。

## 默认画面与摄影基底

```text
胶片人像特写。

双光源夜景布光，主光源为人物头部后上方偏右侧的冷白聚光轮廓逆光，银白色发丝勾边高光，光线穿透发丝，肩膀与衣领边缘包裹一圈柔和光晕，产生朦胧镜头眩光；正面极弱柔光箱补光，低亮度填充面部，不冲掉逆光层次，保留面部自然明暗立体感，逆光强度远大于正面补光，冷白逆光，面部辅光微微暖调，冷暖光影对比。

暗调夜景，背景不是纯黑，带有逆光弥散出来的微弱朦胧环境杂光，背景虚化，浅景深，柔和镜头雾霭，轻微胶片颗粒，温润柔和的曝光，皮肤质感细腻真实，8K高清人像，电影感氛围感，冷调柔光，丰富光线层次，16:9画幅，无文字。
```

## 摄影与 CG 的介质边界

- 默认使用上方摄影基底；用户要求沿用真人院线电影或其他已有效的完整基准时，以用户文本为准，不统一替换成胶片夜景。
- 用户明确选择写实 CG 时，沿用其“写实 CG 3D 数字人像、Octane 渲染、PBR 次世代材质”等成像表达，并移除负面词中排除三维 CG 的内容。摄影与 CG 均可承载精致美型，不将介质标签当作颜值保证。
