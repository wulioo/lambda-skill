# Seedance 分镜脚本

把剧本事实和导演意图转成**观众看得懂、剪辑接得上、Seedance 做得出**的镜头。

## 核心原则

- 先决定观众何时看见什么，再决定景别、机位和运动。
- 每镜只有一个主要叙事任务；无任务镜头删除。
- 镜头由人物行动、信息或主动权变化驱动，不用运镜装饰空白。
- 原文、导演意图和资产分别引用，不在分镜层复制或改写真值。
- 创意分镜可以使用概念资产；生产分镜只能绑定获批冻结的真实参考。
- 不因模型方便牺牲导演必保瞬间，但应通过拆镜降低不可控动作容量。

## 职责边界

### 负责

- 建立原文落实表，保证关键动作、对白、反应、信息和声音不漏；
- 决定景别、机位、构图、视角、调度、反应、运镜、切点和目标剪辑时长；
- 设计轴线、视线、动作、声音和首尾状态衔接；
- 第一遍输出创意分镜，并向美术提出最小视图/状态/首尾帧需求；
- 第二遍绑定获批资产与真实参考，冻结生产分镜；
- 划分 `SHOT` 与 `GEN`，区分目标剪辑时长和请求生成素材时长；
- 将完整镜头执行边界交给 Seedance 生成 Skill。

### 不负责

- 修改剧情、对白、人物动机、观众站位和信息揭示；
- 设计角色长相、服装、场景、道具或资产生图提示词；
- 编写最终 Seedance 提示词、参考调用语法和 API 参数；
- 生成图片、视频、配音或完成粗剪；
- 在没有获批参考图时把创意方案标成生产冻结。

## 生产契约

- 对外交接使用 `project_id/ID@rN`；不得原地覆盖冻结镜头。
- 状态只用 `draft / ready / blocked / stale / accepted / deprecated`。
- `creative-draft` 只供设计和资产补齐；`production-frozen` 才能进入视频生成。
- 每个 `SHOT` 记录精确 `SRC/DIR/ASSET@rev/REF@rev` 依赖；每个 `GEN` 绑定 `SHOT@rev`。
- 同一缺口继承原 `BLOCK-ID`；新镜头执行缺口才新建 blocker，并指定唯一责任 Skill。
- 目标剪辑时长属于 `SHOT`；生成素材时长属于 `GEN`，两者不得混写。

## 输入

必须读取：

1. 原剧本与当前 `SRC-ID`；
2. `seedance-director` 项目简报、试播简报和单集底稿；
3. `seedance-video-prompts/capability-profile.md`；
4. 美术 `visual-bible.md`、`asset-index.md`、`continuity.md`；
5. 第二遍还必须读取 `reference-manifest.md`、核心视觉批准证据、视频执行层的 `sound-plan.md` 与 `post-plan.md`。

只实现“生效/已确认”的 `DIR-ID`。平台未定或能力档案仅为通用规格时，可以做创意分镜，不得冻结生产分镜。

## 工作流

### 1. 选择分镜阶段

- **creative-draft**：导演底稿已通过，概念资产可用；输出镜头设计和资产需求。
- **production-frozen**：平台能力已核实、生产参考已 `accepted`、创意分镜缺口已补齐；输出可生成镜头。

不得跳过第一遍直接假设所有视图和首尾帧已存在。已有成熟资产包时可在同一轮完成两遍，但两种状态仍需分开记录。

### 2. 做原文落实表

逐场列出必须进入成片的事件、动作、原文对白/画外音及说话人、必保反应、信息揭示、关键声音和场景起止状态。每项绑定至少一个 `SHOT`；故意省略的非关键过场写明理由。

### 3. 建立场景镜头脊柱

用最少镜头回答：

- 观众从谁进入；
- 人物目标和第一策略如何建立；
- 阻力何时出现；
- 哪次变招或反应改变主动权；
- 必保瞬间如何被准确看见；
- 场景靠何种信息、决定或情绪切出。

禁止机械套“全景—中景—近景”。

### 4. 设计创意镜头

每镜冻结：

- 镜头任务与观众获得的信息；
- 主体、视角、景别、机位、构图及叙事理由；
- 人物调度、动作触发、反应和表演落点；
- 固定机位或一个有动机的摄影运动；
- 原文对白、声音和切点；
- 首帧、过程、尾帧及前后衔接；
- 目标剪辑时长；
- `SRC/DIR` 与概念 `ASSET@revision`。

### 5. 控制单镜动作容量

一个 `GEN` 优先承载一个空间、一个连续表演意图、一条清晰动作链、有限互动和一个主要摄影运动。以下情况优先拆镜：

- 主体、时间或空间变化；
- 多次精细接触、交接或状态突变；
- 复杂表演、长对白和强运镜同时发生；
- 精确文字必须成为独立信息落点；
- 首尾构图或人物朝向跳变过大；
- 导演必保反应可能被长动作吞没。

### 6. 输出资产补齐清单

只向美术提出镜头真正缺少的：

- 无法由现有视图推断的空间方向；
- 特殊造型/道具/场景状态；
- 对身份、构图或连续性至关重要的首尾帧；
- 后期合成所需的无字底板、屏幕区域或跟踪底图。

每项写 `REQUEST-ID → 影响SHOT → 现有资产为何不足 → 必须锁定的结果`。不写生图提示词，不要求无目的备用图。

### 7. 先做声音预演与轻量 animatic

在生产冻结前完成：

- 视频执行 Skill 冻结声音策略、主角音色/权利和临时对白计时，输出 accepted `sound-plan.md`；
- 分镜用代表帧、临时对白/声音、镜头顺序和目标时长制作轻量 animatic/boardomatic；
- 导演只验收信息顺序、表演节奏、对白容纳度、戏眼和集尾力量。

对白塞不进目标时长、必保反应被吞或节奏不成立时，此时修改创意分镜；不要等付费生成后再发现。

### 8. 第二遍绑定生产参考

美术返回后逐镜核对：

- `ASSET@revision` 与 `REF-ASSET@revision` 状态为 `accepted`；
- 文件哈希和批准证据有效；
- 角色、造型、场景、视图、道具和首尾帧覆盖本镜；
- 物理连续性与上下镜一致；
- 创意分镜为精确文字建立 `POST-REQUEST-ID`；视频执行技术预检在 `post-plan.md` 分配正式 `POST-ID`，生产分镜再绑定该 `POST-ID`。

缺任一生产参考时只阻断相关镜头，不发布 production-frozen。

### 9. 冻结生产镜头与生成单元

使用：

- `SHOT-EP001-001@r1`：剪辑镜头；
- `GEN-EP001-001@r1`：一次 Seedance 生成任务；
- `REF-GEN-EP001-001-01`：该 GEN 内唯一参考映射，禁止跨 GEN 使用裸 `REF-001`。

默认一镜一 GEN。同一连续镜头分段生成时建立多个 GEN，但保留同一 SHOT 的目标剪辑边界。

为每个 GEN 写：所属 `SHOT@revision`、本段目标剪辑时长、请求素材时长、预期可用区间/trim 方向、首尾锚点、明确的 `REF-ASSET@revision` 集合和能力依赖。若一个 SHOT 拆成多个 GEN，各段目标剪辑时长之和必须等于 SHOT 目标时长。若目标镜头 3 秒而平台最短生成 4 秒，则保持 SHOT 为 3 秒，GEN 请求 4 秒并明确裁切，不得把剧情镜头改成 4 秒。

同时登记单集目标时长与允许容差；所有 SHOT 目标剪辑时长之和必须落在范围内，不能靠后期无意义停顿补足。

生产文件必须同时记录能力档案、声音计划、POST 计划、animatic 文件与各自 SHA-256；任一依赖变化后，生产分镜先标 `stale`，不得沿用旧请求。

### 10. 检查节奏与连续性

- 切镜必须落在信息、主动权、视线、动作、声音、情绪或空间关系变化上；
- 关键对白可拍听者，导演必保反应优先；
- 钩子信息给足识别时间，情绪落点留出停顿；
- 检查轴线、左右、视线、出入画、人物位置、造型、伤势、持物、道具状态；
- 上一镜 accepted 尾帧可作为下一镜生产参考时，明确串联关系。

### 11. Animatic 与生产分镜批准

导演先批准 animatic 的镜序、对白容量、戏眼和集尾力量，最终权责人确认进入生产。生产分镜再由分镜岗位验收镜头、连续性和生成单元，导演验收创作落实，最终权责人批准生成。小团队可兼任，但必须按角色分别签署。两个批准文件分别锁定 animatic 与生产分镜 SHA-256；全部 accepted 才能进入生成。

### 12. 退回与变更

退回格式：`BLOCK-ID → 问题 → 影响ID → 唯一责任人 → 解锁证据 → 推荐方向`。

- 缺剧情事实：用户/编剧；
- 导演解释冲突：`$seedance-short-drama-director`；
- 参考资产缺失：seedance-art-assets；
- 平台能力不支持：seedance-video-prompts。

上游 revision 变化时，新建分镜 revision，旧版标 `stale`；只重做受影响镜头。

## 输出

使用 [分镜模板](assets/storyboard-template.md)：

```text
seedance-storyboard/
├── asset-requests.md
├── animatics/EP001.md
├── approvals/animatic-approval.md
├── episodes/
│   ├── EP001-creative.md
│   ├── EP001-production.md
│   ├── EP002-creative.md
│   └── EP002-production.md
└── approvals/storyboard-approval.md
```

发布生产分镜前运行：

```bash
uv run python <skill-dir>/scripts/storyboard_guard.py \
  <项目内seedance-storyboard目录> \
  <项目内seedance-art-assets目录>
```

## 完成标准

- 原文、导演必保瞬间和信息边界全部有镜头承接；
- 每镜任务唯一，镜头选择有叙事理由；
- 创意分镜明确提出最小资产需求；
- 临时对白计时与轻量 animatic 已证明镜序、节奏和对白容纳度；
- 生产分镜只绑定真实、获批、哈希有效的参考文件；
- SHOT 剪辑时长与 GEN 素材时长分开；
- SHOT/GEN 一一或显式一对多，每个 GEN 的生产参考明确，无遗漏、重复和暗中合并；
- 生产文件经过导演批准并锁定哈希；
- 下游无需猜镜头边界、动作顺序、首尾状态和 trim 方向。
