# Camera Movement

分镜拆解时，按需用于运动选型、速度节奏与空间交互。以已确认的导演定调和段落目的为前提；表格写法沿用 [storyboard-format.md](storyboard-format.md)，镜头连接沿用 [shot-design.md](shot-design.md)。

## 一、选择依据

根据本镜希望形成的叙事、情绪、节奏或观看体验，结合人物调度、构图、声音与剪辑选择固定或运动。镜头可以持续观察、延迟信息或形成感受，不要求每镜新增信息，也不要求每场安排运动。

判断拍谁或看什么、与主体保持什么距离、何时改变注意力，再选择相应拍法。摄影机也可以关注环境、光线或空间关系，不必始终跟随人物。情绪和场景案例提供候选，不构成固定对应。

导演风格决定运动的气质与幅度。常规的稳定、可读和空间连续建议不能覆盖已经确定的失衡、断裂、梦境或不可能运动；有意采用这些拍法时，将其表达作用与过程写清。普通运动按备注规范简写，关键或复杂运动再细化必要的起止、路径和节奏。

## 二、基础运动与易混概念

| 运动 | 区分拍法所需的信息 |
|---|---|
| 推进／后拉 | 摄影机靠近或远离什么，注意力如何收拢或空间如何展开 |
| 左右横移 | 摄影机向哪边平移，前后景或遮挡关系如何变化 |
| 水平摇摄／俯仰 | 机位是否固定，朝向从哪里转到哪里；与横移、升降分别说明 |
| 升高／下降 | 高度如何变化，需要时说明是否同时调整俯仰；升高不必然俯拍，下降不必然仰拍 |
| 跟拍 | 跟随对象及前、后、侧的观察关系；需要保持构图时再注明相对距离与位置 |
| 环绕／弧形移动 | 围绕谁，从哪个观察面经哪一侧到哪里；摄影机移动与主体转身分别描述 |
| 手持跟随 | 跟随对象与所需晃动程度，使稳定性符合角色处境和导演风格 |
| 斜向或复合运动 | 以清楚的主路径组织位移、升降、摇摄或焦点变化，使组合服务同一表达意图 |

有歧义时，注明左右是画面方向、人物自身左右还是场景方位。环绕优先描述起始面、经过哪一侧和结束面；使用顺／逆时针时，以俯视路径为参照。

推进改变观察位置与透视；原地变焦改变焦距与取景范围，不改变观察位置。两者分别说明，不把推进统一解释为“压缩空间”。焦点转换说明清晰对象的交接，与变焦分开。

选择 Dolly Zoom（移动变焦）时，摄影机推进并相应缩短焦距，或后退并相应增加焦距，使主体画面大小近似不变，同时改变背景透视关系；运动与变焦需协同，不把任意“推进＋变焦”都标成此效果。

景别沿用现有定义，不另建一套层级。主观视角对应角色的观看位置和方向，可以同时采用平视、俯拍或仰拍；机位高度、拍摄角度与叙事视角分别判断。

## 三、速度与节奏

分别决定摄影机运动速度、人物动作速度、画面播放速度与切镜频率。紧张场景可以用固定观察或极慢运动，快速移动也可以发生在长镜头中。

| 节奏选择 | 可考虑的组织方式 |
|---|---|
| 缓慢匀速／持续漂移 | 逐步靠近、延迟揭示、维持感受或形成观看节奏，不要求途中不断出现新事件 |
| 急推／快速后拉 | 突然强调对象或展开处境，考虑观众何时能读清关键画面 |
| 由慢到快／顿推 | 与行动升级、注意力突变或音乐节拍配合，交代变化所落在的节点 |
| 减速／缓停 | 需要落在人物反应、目的地或某种构图时采用，不作为每镜默认结尾 |
| 匀速跟随／斜向跟随 | 保持行动关系，或在同一过程中改变人物与环境的分量 |
| 甩镜／突然急停 | 在明确的注意力对象间转换；也可按剪辑意图在运动中切出 |

起停、变速或持续运动可依据动作、信息、声音、音乐或段落呼吸决定。运动中切出、人物出画后继续移动、固定停留都可以成立。时长应容纳所需动作和观看过程，无依据时不编造精确速度、焦距或轨道距离。

## 四、场景与情绪的应用机制

以下按视觉机制组织候选，场景仅作例子。天气、时段、火光和建筑结构沿用已有设定；效果结合人物处境、表演、光线和声音判断。

| 视觉机制 | 可用手段与场景例子 | 表达上的选择 |
|---|---|---|
| 改变观看距离 | 慢推、顿推或急拉，靠近反应或展开周围空间 | 靠近可形成亲近、凝重或侵入感；拉远可形成疏离，也可完成喜剧揭示 |
| 沿纵深进入 | 推进或跟随，利用雨线、隧道灯列、走廊重复结构 | 用运动视差形成深入、期待或不安；具体速度由段落节奏决定 |
| 遮挡与显露 | 横移、跟拍或固定构图，利用窄室门框与穿行人群 | 可呈现局促、寻找、压迫或日常在场感，取决于人物行动与通路 |
| 改变尺度与俯仰关系 | 后拉、升降或摇摄，展现雪原、高空城市、古建筑 | 可交代布局、突出体量或人的渺小；不把高位俯拍必然解释为无力 |
| 前后景流动 | 平移、弧形移动或环绕，利用夜景灯火、贴水波光与雾中层次 | 可形成舒缓、迷离、陌生或被包围的体验；确定环绕中心或摇摄范围 |
| 动能与稳定性变化 | 低位跟随、斜向跟拍、手持、甩镜或变速，用于赛事及火光中的行动 | 可形成冲击、兴奋或混乱；依据既定风格决定保留多少方向与动作信息 |

同一手段可以产生不同效果。将情绪目标落实为距离、构图、遮挡、注意力和观看节奏的选择，避免只写“增加氛围”，也不为了增加运动而改变剧情信息顺序。

## 五、镜头与角色、物体的交互

- **背面绕至正面：** 需要先隐藏再显露面部时，说明经人物哪一侧移动，以及人物是否保持原站位和朝向；避免以人物转身替代摄影机环绕。
- **门窗与织物穿越：** 确定开口、通路和到达空间，以接近、遮挡、掠过和重新显露承接空间。常规实景路径经过可用开口；风格化穿墙或穿玻璃依既定拍法表达，不无意混用两者。
- **前景遮挡与焦点交接：** 写清谁遮住谁、解除后看见什么。遮挡不自动引发失焦；需要把注意力由前景交给主体时，再指定焦点转换。
- **过肩到主观视角：** 先建立人物视线，终点与角色观看位置和方向相符时才标为主观视角；越过肩膀本身不等于完成主观转换。
- **动作与声音接力：** 人物停步后摄影机可以停下，也可继续看向前方；画外声、对白或音乐也可引导转向和切镜。依据注意力安排选择，不必先显露声源。

## 六、不同表达目的的示例

以下为局部写法示例，按当前剧情和导演风格选用，不作为通用镜头序列。

- **克制对话／固定观察：** 固定双人中景，一人递出纸页，另一人迟迟不接。保持悬空的纸页与双方身体同框，由反应间隔呈现关系，无需追加推进。
- **节拍行动／运动中切出：** 摄影机侧跟奔跑者，在人物经过门框、身体被遮挡的瞬间切到门另一侧，承接原行进方向；镜头随动作切出，不先减速停稳。
- **悬念／信息揭示：** 摄影机沿走廊缓移，前景门框逐步让开，露出门后的听者；说话者仍在画外，对白继续。显露的时机决定观众何时知道有人旁听，可按段落需要停留或继续移动。
- **诗意长镜头／持续感受：** 摄影机缓慢穿行庭院，人物出画后继续经过树影与窗帘，环境声延续；让人物与空间的距离逐渐展开，不为证明运动必要而添加新事件，也不强求以停稳结束。
