# 人物情绪表演思考方法

用于优化已有提示词中的开心、悲伤、难过、愤怒、紧张等情绪及其变化。将以下思考用于理解与取舍，最终仍在原提示词结构内优化表演，不输出人物分析表，不替用户编写新的内心戏。

## 一 从已有情境读出人物状态

先区分输入明确给出的内容与尚未说明的内容：当前事件、人物关系、正在进行的行为、情绪方向和强度、已有表演、视线对象、台词、取景与时长。

依据这些信息判断：

- 人物此刻正在做什么，想完成什么；有互动时，他想让对方明白、接受、停止或继续什么。
- 情绪是自然流露、努力维持、刻意掩饰、受到压制，还是已经释放。
- 是否存在表达与行动之间的阻碍；有阻碍时，究竟是什么做不到。
- 已有什么身体或声音变化，它们是否足以表达当前状态。
- 哪个已有事件、词句或对方反应改变了他；变化之后，他继续、改变、收回还是暂时做不到原来的事。

目标和阻力不必每次都存在或写出。只有“她开心地看着孩子”时，可以细化已有喜悦和注视，不补造获奖、重逢等起因；静态人物已经面露难过时，也不需要虚构一段失去或告别。信息不足以支持复杂心理时，使用与已知情绪相容的表达，保留未确定部分。

## 二 判断这份情绪怎样进入当前行为

情绪名称提供方向，具体表达取决于情境、当前行为以及人物对情绪的处理。同样开心可以直接笑开，也可以努力收住笑意；难过可以沉默、流泪、继续处理事情，也可以充分痛哭。它们不构成固定的强弱次序。

| 已有情境 | 需要判断的表演关系 |
| --- | --- |
| 开心并自然流露 | 喜悦怎样进入已有笑容、注视、说话或行动；无需制造压抑与阻力 |
| 开心却努力保持郑重或掩饰 | 哪些喜悦自然泄露，人物怎样收住或调整表达 |
| 难过却仍要完成事情 | 情绪怎样影响已有行动，人物怎样努力继续；不能擅自中断锁定的操作 |
| 难过却要安慰或挽留对方 | 自身情绪与对对方的行动目标怎样同时成立 |
| 明确失控、放声哭笑或激烈表达 | 保留释放程度和既有动作，不自动改成低声、轻微或含而不露 |
| 已有稳定情绪或明确不回应 | 判断现有表达是否已经足够，不强行安排转折与恢复平静 |

同场人物也不需要相同的表演。原教程中，男人依靠礼貌和否认把悲伤压回身体，女人因担心连接断开而追赶；两人都悲伤，却有不同的气息、语速和视线方式。可迁移的是依据各自状态区分应对方式，不是按性别分配内收与外放。

## 三 存在拉扯时分析三股力量

**生理泄露＋自我控制＋关系目标**，用于情绪正在出现、人物又试图维持某种状态的情境。它源于原教程的克制悲伤案例，可迁移到有相同结构的其他情绪，不作为所有表演的必填公式。

| 组成 | 要判断什么 | 原教程中的作用 |
| --- | --- | --- |
| 生理泄露 | 情绪已经从哪里被看见或听见 | 红湿的眼眶、困难吞咽和气息失控暴露痛苦 |
| 自我控制 | 人物正在努力压住、调整或维持什么 | 回避目光、压回哭腔，努力不让眼泪落下 |
| 关系目标 | 在这种状态下，仍想向对方完成什么 | 自己接近崩溃，仍先减轻对方的罪恶感 |

三项要共同解释行为。眼湿是情绪泄露，移开目光是维持自己，努力安慰对方则解释了他为什么还在组织语言。只堆出湿眼、低头和吞咽，仍可能没有人物关系。

关系目标可以是安慰、挽留、拒绝、解释、自证或结束谈话，不限定为照顾别人。没有关系目标时，依据当前行动理解人物；没有克制时，保留自然流露或释放；控制失败时，可以承接失控，不自动让人物收回情绪。

对于有明确阻力的表演，重点可以是“想笑却努力收住”“想解释却难以发声”这类同时存在的力量。不要据此把直接开心、充分哭泣或坦然接受判为低级表演。

## 四 把关键心理关系落实为可观察变化

遇到重要变化表达不足时，内部追问：

**已有触发是什么 → 人物怎样理解 → 想作出什么回应 → 是否遇到阻碍 → 身体与声音怎样变化 → 行动或表达怎样继续。**

只分析输入支持且影响本次优化的部分。没有阻碍就不安排失败，没有转折就不补事件；这是一条检查因果关系的思路，不是要求按阶段表演的时间表。

从以下渠道选择有用的细节：

| 渠道 | 可以具体到什么程度 | 选择依据 |
| --- | --- | --- |
| 视线 | 看谁、落在哪里、何时靠近或避开、何时重新看回 | 是否说明关注、确认、回避或连接；遵守锁定视线 |
| 面部 | 笑意、眉眼、嘴角或下颌正在变化、被维持或被释放 | 是否能读到重要转折，避免逐部位罗列表情 |
| 呼吸与喉部 | 呼吸怎样支持、打乱或阻碍表达，是否有吞咽或吸气失败 | 当前情绪和已有表达是否需要，不把吞咽当通用动作 |
| 声音 | 音量、音高、重音、语速、气息、声音完整程度怎样变化 | 是否服务于已有发声与当前意图；保留既定声音和节奏 |
| 手与身体 | 当前动作怎样继续、悬停、收回、收束或释放 | 是否改变互动或表达；服从站位、支撑、道具和动作锁定 |

细节应适合媒介。静态画面只选择同一时刻可共存的状态；看不清脸时不写微小面部变化；无声片段通过可见表演表达，不因分析声音而自动增加发声。

“人物难过”有时与主要行为组合便足够。只有关键过程缺失时，才从心理关系细化到可观察证据，不以增加动作数量证明优化。

## 五 保持行为完整并保留表演的发展

常见行为保持整体，重点转折才展开它的受阻、改变或收束。原教程中抬手请求停止、手悬在原处、最后失力落下是一条有含义的动作线；改成反复挥手会改变关系。连续倒水、修理等动作也不能被额外吞咽、抿嘴或转头机械切开。

心理理解与最终措辞可以不同：内部理解“他想解释却做不到”，输出可只写“嘴唇已经准备开口，吸气后仍没有发声，随后困难地吞咽”。不要把整段心理分析灌入提示词，也不要把本来同时发生的反应改成依次展示的身体步骤。

情绪的发展既包括强度，也包括处理方式：从控诉到自证，从努力掩饰到流露，或从无法解释到暂时能安慰对方。原教程另一组争执中，女人从愤怒控诉转向暴露委屈，后句声音可以更轻。依据已有内容承接这些变化，不把“越来越难过”统一变成越来越响、越来越多眼泪。

连续段落和镜头中，承接已经形成的目光、手势、身体紧张、泪水、呼吸与声音状态；它们可以因新事件变化，不能因换镜而归零。相同微动作若多次发生，要能解释各次作用，避免等间隔循环。

## 六 将思考用于实际优化

按当前缺项使用以下方法，不要求每次完整展开：

1. 识别已有情绪、当前行为和明确的表达方式，保留已经成立的部分。
2. 找出重要变化发生处，确认触发和目标是否由原文支持。
3. 判断是否有情绪与控制、行动或关系之间的拉扯；有则分析，无则沿原方向表达。
4. 选择能让这一变化被看见或听见的细节，检查它与说话、操作、取景及时间是否相容。
5. 在原段落内改写、合并或补足，检查与下一段状态的承接。

可在内部简记“当前目标与情绪 → 关键触发 → 表达或行动变化 → 后续状态”，不要求输出新增人物内核、时间轴或分析栏目。已有台词的增删、重复和截断仍遵守主文件的授权边界；涉及多人对白时结合对应方法继续检查。

## 七 用对照情境校准取舍

以下示例是方法迁移，用来校准保留与细化，不是原视频逐字引文。

### 自然流露的开心

输入：
> 固定近景。她听到好友录取的消息，开心地笑着说：{太好了！}

输出：
> 固定近景。她听到好友录取的消息，开心地笑着说：{太好了！}

情绪、对象与行为已经清楚，可以直接保留。没有掩饰要求，不追加压住笑容、停顿或激动到说不出话。

### 开心与郑重同时存在

输入：
> 固定近景。她听见自己获奖，开心却努力保持颁奖场合的郑重，微笑着说：{谢谢。}

输出：
> 固定近景。她听见自己获奖，笑意自然扬起，又努力收住，维持着郑重的微笑说：{谢谢。}

笑意与控制来自原有要求，细写它们的关系即可；不新增上台、鞠躬、含泪或获奖经历。

### 难过且充分释放

输入：
> 固定中近景。他坐在原地放声痛哭，肩膀随哭泣起伏，没有努力掩饰。

输出：
> 固定中近景。他坐在原地放声痛哭，肩膀随哭泣起伏，没有努力掩饰。

释放本身已经成立，不套用“不落泪”“压回哭腔”或“困难吞咽后恢复平静”。悲伤强度不能因追求细腻而被削弱。

静态难过、重要情绪转折与持续操作中的取舍，继续参照[人物表演与场景动态示例](微表情优化示例.md)。

## 八 复查与局部修正

检查情绪是否符合原方向、强度和表达方式；关键细节是否有依据，是否帮助读出状态或变化；镜头是否能读到；是否影响已有行为、台词和时长；前后状态是否连续。

只修改失败的部分：变化含混就补清对应反应，动作过多就合并冗余，状态断开就修正承接。已成立的情绪和行为继续保留，不同时重写人物关系、风格、台词和镜头。

本方法结合《对白表演提示词思路详解与逐段记录》及《人物表演通用原理与描述方法》中的表演分析整理，独立保存在 Skill 内，无需访问原工作目录。原教程为 Foyege弗曳哥的[对白表演提示词教程](https://www.bilibili.com/video/BV1jLug6LEgp/)，重点讨论情绪受阻的双人对白；开心、无对白与其他情境的处理按上述条件迁移，不声称原片逐项演示过。平台操作、素材外观、镜头参数和案例固定数值不作为表演规则。
