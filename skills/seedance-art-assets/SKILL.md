# Seedance 美术资产

把剧情视觉要求做成**能识别、能复用、有真实文件、可供 Seedance 调用**的参考资产。

## 核心原则

- 先定视觉系统，再写提示词；提示词只表达会影响身份、空间、道具功能和跨镜一致性的内容。
- 先复用，再做状态变体，最后新增；不为同义描述重复建资产。
- 每个资产只保留 3—6 个高辨识锚点；全局风格只在视觉圣经写一次。
- 资产图锁定身份与空间，不预演无关剧情；镜头专用首尾帧只按创意分镜需求制作。
- 严格区分：**剧本事实 / 导演约束 / 美术设计 / 用户批准**。
- 没有实际文件、哈希与批准证据的图片，只是候选，不是生产参考。

## 职责边界

### 负责

- 建立试播范围内最小可用的角色、造型、场景、视图、道具和状态资产；
- 确定视觉圣经、稳定识别锚点、复用关系及物理连续性；
- 编写精简资产生图提示词；
- 在用户要求生产且图像工具可用时生成候选图，筛选后交用户/导演批准；
- 接收创意分镜提出的视图、状态和首尾帧需求，补齐实际参考图；
- 登记本地路径、文件哈希、尺寸、来源、授权、修订版、责任人与批准状态；
- 冻结生产参考，向生产分镜和 Seedance 发布准确 `ASSET@revision / REF@revision`。

### 不负责

- 修改剧情、人物动机、关系或信息揭示；
- 决定人物表演、观众视角和导演戏眼；
- 决定景别、机位、运镜、切点、镜头时长或生成单元；
- 写 Seedance 视频提示词或生成视频；
- 把未生成、未授权或未批准的图片写成“已冻结”。

## 生产契约

- 所有短 ID 只在 `project_id` 内唯一；对外交接使用 `project_id/ID@rN`。
- 对象状态只用：`draft / ready / blocked / stale / accepted / deprecated`。
- `ready` 表示候选可审；`accepted` 表示已批准并冻结，才能进入生产分镜。
- 每个逻辑对象只能有一个当前版本；记录 `revision`、`supersedes`、来源 `SRC/DIR`、责任人和影响范围。
- 缺失事实复用同一个 `BLOCK-ID`，不得在下游另起同义阻断。
- 文字真值归 `SRC`，导演解释归 `DIR`，美术只拥有外观、物理状态和参考文件。

## 输入

优先读取：

1. 本次集数剧本；
2. `seedance-director/project-brief.md`、试播简报和对应单集导演底稿；
3. 导演给美术的逐条约束；
4. `seedance-video-prompts/capability-profile.md`（生产冻结前必须为已核实版本）；
5. `seedance-storyboard/episodes/*-creative.md` 中新增视图/状态/首尾帧需求（第二遍时）；
6. 用户参考图、现有资产、授权证明和发布规格。

只使用当前 `SRC-ID` 和“生效/已确认”的 `DIR-ID`。遇到待确认、待复核或已失效决定，只阻断依赖对象。

## 工作流

### 1. 预检真正影响视觉的事实

检查角色身份、时代地域、制作形态、核心场景行动、关键道具功能、精确文字和参考图授权。只有不同答案会改变角色身份、核心风格、重要道具可读性或剧情泄露时才问用户，每轮最多 3 问。

精确姓名、信件、手机界面等原文未给出的事实，建立 `BLOCK-ID`，责任人写“用户/编剧”；不由美术补写。

### 2. 建立视觉圣经

只冻结全项目真正需要统一的内容：制作形态、时代地域、社会质感、人物区分、色彩/光线逻辑、材质真实度、竖屏构图原则和禁止漂移项。

视觉方向先产出少量风格候选；用户/导演只批准会决定全片的方向，不逐项确认普通颜色和家具。

### 3. 建立概念资产基线

使用稳定 ID：

- `CHAR-001`：角色身份母版；
- `LOOK-001`：服装、发型、伤势、年龄阶段、伪装等可见变体；
- `LOC-001`：可复用空间；
- `VIEW-001`：分镜确实需要的空间方向；
- `PROP-001`：承担身份、证据、动作、揭示或连续性的道具；
- `STATE-001`：资产关键物理变化；
- `FRAME-EP001-001-S` / `-E`：创意分镜提出的镜头专用首/尾帧。

试播只建立 EP001—EP002 必需资产。普通情绪不是造型；普通装饰不是资产。

### 4. 设计外观与物理连续性

- 角色母版：年龄段、体态、面部结构/画风识别通道、发型轮廓和少量不可替代特征；
- 造型：只记录剧情可见变化及基于哪个角色母版；
- 场景：先保证入口、出口、遮挡、对话距离、人物路径和关键区域，再装饰；
- 道具：冻结剧情功能、识别锚点、状态与持有人；精确文字默认做无字底板并登记后期排字；
- 连续性：逐场只记录服装、伤势、污损、持物、场景和道具等可见物理事实。

人物知情、关系和情绪真值只引用导演底稿，不在美术层复制解释。

### 5. 写生图提示词

每条自然中文提示词只写：

1. 唯一主体和用途；
2. 剧情身份或空间功能；
3. 3—6 个冻结视觉锚点；
4. 必要构图、视角、姿态或陈列；
5. 与视觉圣经相关的光线、材质和风格；
6. 必须保留及不得出现的高风险项。

身份图使用中性姿态；场景图优先空镜；道具清楚展示形态与状态。删除“8K、杰作、极致、电影级”等无叙事价值词。

### 6. 第一遍发布：概念基线

输出资产规格和提示词，状态可为 `draft/ready`。此时允许创意分镜规划镜头，但必须声明：**没有 accepted 参考图，不得发布生产分镜。**

### 7. 接收创意分镜回传

合并创意分镜提出的最小新增需求：必要反打视图、特殊状态、首尾帧、精确道具角度。若请求只是普通表情、无意义备用角度或重复资产，拒绝并说明现有资产如何满足。

镜头专用帧由分镜定义画面任务和构图边界，美术负责实际生图与一致性，不改镜头意图。

### 8. 生成、选片与批准

仅在用户要求生产且有图像工具时生成。每个核心对象先做少量候选，按以下顺序筛选：

1. 身份/剧情功能正确；
2. 与视觉圣经和父资产一致；
3. 后续视角、动作与 Seedance 可复用；
4. 无明显肢体、文字、透视和风格错误。

视觉方向、主角脸、核心场景和关键道具必须经过用户/导演批准。其余低价值资产由美术按冻结原则处理。未获批准写 `ready`，不得写 `accepted`。

### 9. 冻结 reference manifest

每个获批文件登记：

- 唯一 `REF-ASSET-ID`、绑定 `ASSET-ID@revision`；
- 本地稳定路径；
- SHA-256、尺寸、格式；
- 生成/来源信息、提示词版本；
- 用途和不得影响项；
- 版权/肖像授权；
- 美术岗位验收、导演/最终权责批准、证据、时间与状态。

`reference-manifest.md` 同时锁定 `visual-bible.md`、`asset-index.md`、`continuity.md` 的 SHA-256；每条 REF 批准还必须锁定其 `ASSET@revision + asset-index hash + 图片 hash`，防止只锁图片却改绑身份、首尾帧或连续性。同一 REF 逻辑 ID 只能有一个 `accepted` 修订。

美术不管理平台 URL、asset ID 和临时有效期。它们由 `seedance-video-prompts` 在每个 GEN 的上传映射中建立；美术只对本地权威文件负责。

生产清单同时锁定当前能力档案的路径、revision 与 SHA-256。平台未定或能力档案变化时，概念资产仍可继续，但生产参考不得新标 `accepted`；已冻结参考先标 `stale` 并重新核对格式、比例、提交形式与参考上限。

只有文件存在、哈希匹配、授权明确且状态 `accepted` 才能供生产分镜与 Seedance。公网 URL 只是提交副本，本地文件才是稳定归档。

### 10. 变更与失效

上游事实、导演决定或父资产变化时建立新 revision，旧版标 `stale` 或 `deprecated`，列出受影响 `VIEW/FRAME/SHOT/GEN`。同一逻辑对象不得同时存在两个 `accepted` 修订。不得原地改写已冻结文件，也不得在视频提示词里临时换脸或重画资产。

## 输出

使用 [美术资产模板](assets/art-assets-template.md)：

```text
seedance-art-assets/
├── visual-bible.md
├── asset-index.md
├── continuity.md
├── image-prompts.md
├── reference-manifest.md
└── approvals/visual-approval.md
```

Markdown 是权威规格；图片是受 manifest 管理的生产文件。发布生产参考前运行：

```bash
uv run python <skill-dir>/scripts/art_assets_guard.py <项目内的seedance-art-assets目录>
```

## 完成标准

- 概念资产只覆盖当前制作范围，主角母版可扩展；
- 每个对象有来源、revision、单一状态和明确用途；
- 角色可区分、场景可调度、道具能完成剧情功能；
- 创意分镜需要的视图、状态和首尾帧已补齐；
- 生产参考都有真实文件、哈希、授权和批准证据；
- 生产参考声明的图片尺寸/格式与真实文件一致；
- 只有 `accepted` 参考进入生产分镜与 Seedance；
- 提示词短、准，没有越权表演、镜头设计和无效画质词。
