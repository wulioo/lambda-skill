## 人物布光

### 1. 伦勃朗光

- 机制与表现：侧上方主光塑造面部，鼻影与面颊阴影相接，背光侧眼下留有小块三角形受光区。图案受脸型、朝向和灯位影响，不固定为某个精确角度。
- 用途：面部体积与较强的明暗层次。近景或能够辨认面部的中景更容易读到。
- 可用表达：侧上方主光照亮朝向光源的面颊，另一侧面颊保留阴影，眼下形成小块三角形亮区。
- 边界：不默认纯黑背景或黑色电影风格；远景、背影、无五官角色不强行生成面部光斑。

### 2. 蝴蝶光

- 机制与表现：主光位于脸部正前方偏上，鼻下形成接近蝶形的小阴影，左右面颊受光较对称，颧骨和下颌的阴影提供塑形。
- 用途：正面肖像与面部结构呈现，反差由补光决定。
- 可用表达：正前上方的柔和主光均匀照亮额头和双颊，鼻下保留小而清楚的蝶形阴影。
- 边界：“派拉蒙式布光”是常见的同类称呼，不限定某种灯具，也不要求环形光源；人物转侧后允许图案随姿态变化。

### 3. 分割光

- 机制与表现：主光从一侧照入，使面部一侧明亮、另一侧显著较暗，明暗交界接近面部中线。
- 用途：较强的方向感、已有的压迫或对立氛围。
- 可用表达：侧面主光照亮靠光源的半边脸，另一半留在深阴影中，鼻梁附近形成清楚的明暗交界。
- 边界：不自动将阴影写成绝对纯黑，也不据此新增“双重人格”等剧情事实。

## 人物与背景分离

### 4. 边缘轮廓光

- 机制与表现：后方或侧后方光源在头肩、衣服或身体外缘形成窄亮边，使轮廓与背景分离。
- 用途：辨认人物轮廓，建立人物与背景之间的空间关系。
- 可用表达：侧后方来光沿头肩与衣服外缘形成窄亮边，正面明暗保持当前场景的照明状态。
- 边界：逆光是来光方向，轮廓光是其可能形成的表现之一，二者不完全等同。剪影由较暗主体与较亮背景的对比呈现，不必须有外缘亮边；面部细节可按目标隐去，但所需人物或动作仍应通过侧脸、头肩或姿态轮廓辨认。用户要求读清表情时，保留相容的正面照明，不同时强求完整黑色剪影。不因逆光自动添加梦境泛光、浅景深或飘动发丝。

### 5. 发丝光

- 机制与表现：光主要落在头发外缘或局部发丝，突出头发的透光、细丝和与背景的分离。
- 用途：头部层次与可见发丝的质感。
- 可用表达：侧后方日光照亮头发外缘，少量散落发丝透出细亮线，脸部仍由原有主光照明。
- 边界：不要求每根发丝发亮，不自动增加长发、散发或风；与全身轮廓光区分作用范围。

### 6. 侧逆光

- 机制与表现：光从主体侧后方照来，既勾出外缘，也照亮一部分侧面，形成不同于正面主光的身体层次。
- 用途：人物与空间纵深、衣料边缘和身体体积。
- 可用表达：光从人物靠窗一侧的后方照入，照亮侧面肩背和衣料外缘，正面由室内反射光适度照明。
- 边界：说清相对人物和摄影机的位置，不硬套资料中的“135°”。强度不应无依据盖过当前主光。

## 整体影调

### 7. 低调光

- 机制与表现：较大面积由暗部构成，亮部集中在少数人物或物体上，主光与暗部存在明显反差。
- 用途：聚焦、遮蔽、克制或已有的紧张氛围；也可用于白昼室内。
- 可用表达：檐下空间保持较暗，亮区集中在靠窗的人物与桌面，阴影细节按叙事需要保留。
- 边界：不等于全画面欠曝或夜景。不为了低调风格抹掉用户要求看清的动作与建筑。

### 8. 高调光

- 机制与表现：画面以较亮层次为主，照明较均匀，阴影轻，反差较低；不依赖高光大面积裁切。
- 用途：开放、清新、轻快或用户指定的明亮氛围。
- 可用表达：较大面积的柔光与反射光照亮人物和环境，阴影浅而柔和，白色衣料与墙面仍有层次。
- 边界：不等于白雾、白色光幕或过曝。白昼强烈明暗对比可以是另一种影调，不自动归为高调光。

## 场景光源与遮挡

### 9. 月光照明

- 机制与表现：按夜景中的月亮方向或模拟月光建立照明；冷暖由白平衡与风格选择，月光不必须深蓝。
- 用途：夜间环境与有限照明下的空间层次。
- 可用表达：月光从上方偏侧照入，照亮朝向天空的屋顶与人物肩部，檐下仍较暗。
- 边界：用户锁定白昼时不引入月光；不默认增加湖泊、湿衣、雨水或烟雾。

### 10. 聚光灯照射

- 机制与表现：定向光集中照亮一定范围，在人物、地面或背景形成局部亮区，周围区域相对较暗。
- 用途：舞台重点、已有事件的信息揭示或注意力集中。
- 可用表达：上方定向光照亮台心人物和脚下的小片地面，亮区边界及人物投影与光源方向一致。
- 边界：清透空气中可清楚呈现受光区域，不必画出空中完整光锥。可见光束另按体积光处理，不为其显形默认加雾。

### 11. 窗户光

- 机制与表现：光由已有窗户进入，窗户的朝向、大小、天空状态和是否直射共同决定光的软硬与投影。
- 用途：有来源依据的室内照明，连接人物与建筑空间。
- 可用表达：窗外散射日光从人物一侧照入，靠窗的面颊和桌面较亮，室内深处逐渐变暗，暗部由墙面反射光照明。
- 边界：窗户光不总是柔光；直射日光可以形成硬边投影。不能为了套用方法增加原本没有的窗户。

### 12. 缝隙光

- 机制与表现：光通过已有窄缝或局部开口，投射成受开口形状控制的窄亮带，周围保持较暗。
- 用途：局部信息、既有的窥视或遮蔽关系、较强注意力引导。
- 可用表达：日光穿过半掩门的窄缝，在地面和已有物体上形成一道细长亮带，缝外区域保持原有暗部。
- 边界：有接收表面的亮带不等于悬浮激光束，不自动增加门缝、窥视行为或眼部特写。

### 13. 百叶窗光影

- 机制与表现：定向光被已有百叶窗叶片、窗格或栏杆等规则结构切割，在可见接收面形成对应结构的亮暗图案，图案随表面形状与透视变化。
- 用途：空间结构、已有的禁锢或分隔氛围。
- 可用表达：日光穿过百叶窗，在墙面与人物肩部投下平行条纹，条纹随墙面与衣料转折改变形状。
- 边界：不将条纹平铺到所有物体或漂在空气中，图案应来自当前已有结构，不将窗格换成百叶窗。区分前景栏杆遮住人物的实体遮挡与栏杆投在皮肤上的阴影；栏杆入镜本身不能证明条纹投影存在。

## 空气与光学表现

### 14. 体积光

- 机制与表现：定向光在空气中的雾、烟或颗粒上散射，形成可见路径或光束，范围、浓度与背景明暗决定显形程度。
- 用途：用户需要的空间层次、介质存在或光路呈现。
- 可用表达：已有轻薄烟尘只存在于窗边的局部区域，斜入日光在该区域形成可辨认的光束，其他空间保持清楚。
- 边界：未经用户要求或场景依据不新增雾、烟或扬尘。明确无雾、空气清透时，优先表现受光表面和投影，不为显形铺灰白介质；不声称真空或无散射介质中出现实体光柱。

### 15. 梦境柔光

- 机制与表现：一种审美目标，可用柔和阴影、受控高光扩散、较低局部反差等表达；不同手段不是同一种物理机制。
- 用途：用户明确要求的柔和、梦境、回忆等视觉方向。
- 可用表达：人物主要轮廓仍可辨认，亮部边缘出现轻微扩散，阴影过渡柔和，扩散局限于亮部附近。
- 边界：不因名称新增梦境剧情。用户排除泛光时，可保留柔和照明而不用高光扩散；不默认全画面白纱或将远景建筑抹平。

### 16. 镜头眩光

- 机制与表现：较强光源进入或接近镜头视野，镜头内部反射与散射产生光斑、鬼影、条纹或幕状眩光，表现随镜头和光源关系变化。
- 用途：用户需要的逆光光学质感，或既有摄影风格。
- 可用表达：太阳靠近画面边缘时产生少量局部光斑，光斑位置与光源方向关联，主体仍清楚可辨。
- 边界：不等同于物体发光、空气中的光束或场景起雾。固定镜头和固定光源不无故出现四处游走的光斑；用户排除扩散泛光时，不默认添加降低全画面反差的幕状眩光。

## 选择与组合

光线类型与情绪之间没有固定的一一对应。硬光可以表达冲突，也可以呈现晴朗日常；柔光可以温和，也可以通过空间与叙事形成不安。情绪方向只用于选择当前设计，不据布光反推人物心理或新增事件。

- 清楚的空间纵深：优先光源方向、亮暗分区、遮挡投影与材质差异，空气介质只在目标需要且允许时使用。
- 柔和但清透：柔光源、自然补光和渐变阴影可以同时成立，不需要梦境泛白或雾层。
- 强烈白昼对比：直射日光照亮开敞区域，遮阳或檐下区域较暗，天空与环境反射光按需要提供暗部照明。
- 人物近景塑形：根据朝向选伦勃朗光、蝴蝶光或分割光，再决定是否补光；不同时强求三种面部图案。
- 方法相冲突时：保留用户目标和主导方法，去掉没有依据的辅助效果，不用堆叠更多形容词掩盖冲突。

## 基础光线与照射方向

### 17. 自然光

- 机制与表现：利用太阳、天空等自然来源，按时段、天气、开口和遮挡建立照明。直射日光可形成硬边阴影，天空散射或云层扩散后的光通常较柔。
- 用途：生活感、环境可信度，以及与当前时段和天气相容的照明；也可用于有明确戏剧性的设计。
- 可用表达：日光照亮无遮挡的地面和朝阳表面，檐下由天空散射与环境反射光照明，亮暗关系与建筑遮挡一致。
- 边界：自然光不固定等同柔光、低反差或纪实风格；“自然”不表示未经设计。室内窗户光是它的一种具体进入方式，不重复创建“自然窗光”条目。

### 18. 硬光

- 机制与表现：光源相对主体的有效发光范围较小，投影边缘较清楚，面部或物体上的明暗过渡较短。补光可以降低整体反差，同时保留较硬的主光阴影。
- 用途：读清形体、纹理与遮挡投影，或表达当前剧情需要的强方向感。
- 可用表达：直射日光在墙面和地面形成清楚的投影边缘，衣料褶皱的亮暗转折明确，阴影亮度由环境反射光决定。
- 边界：不把强度高当作硬光的唯一依据，也不自动对应炎热、愤怒或冲突。按当前材质处理高光，不将所有表面写成油亮。

### 19. 柔光

- 机制与表现：光源相对主体的有效发光范围较大，阴影边缘和面部明暗过渡较缓。柔光仍可具有方向和较明显的亮暗反差。
- 用途：平缓塑形、呈现细腻材质，或用户需要的温和视觉方向。
- 可用表达：大面积柔光从人物一侧照入，面部与衣料阴影过渡平缓，暗侧亮度由已有反射光决定，轮廓与背景细节保持清楚。
- 边界：不等于全画面模糊、梦境泛光、高调影调或无阴影。“影棚柔光”是受控环境中的应用，“窗边柔光”是窗户光的应用，按来源分别落地，不另建同义方法。

### 20. 侧光

- 机制与表现：光主要从主体一侧照入，不同朝向的表面受光差异形成体积、纹理与空间层次。
- 用途：面部、衣料、物体或建筑的立体感，适用于多种景别。
- 可用表达：侧向来光照亮柱子和人物朝向光源的表面，背光面较暗，投影落向相反方向，木纹与衣料褶皱的层次清楚。
- 边界：侧光不必须形成面部中线分割，也不自动出现伦勃朗三角亮区；这两种面部图案只有在朝向、灯位和取景支持时才采用。侧光本身不构成“神秘”的剧情事实。

### 21. 顶光

- 机制与表现：光从主体上方照下，朝上的表面较亮，眉弓、鼻下、下颌或其他突出结构下方形成阴影，效果随光源范围和补光变化。
- 用途：表现已有天窗、顶灯或上方来光的空间，也可用于当前需要的孤立、压迫或舞台重点。
- 可用表达：上方来光照亮人物头顶与肩部，眉弓和下颌下方留有阴影，地面受光与身体遮挡相容。
- 边界：不为了顶光增加原本没有的灯具或光锥。顶光不固定等同审讯或恐怖，不用过深眼窝阴影遮掉用户要求读清的眼部信息。

### 22. 底光

- 机制与表现：光从主体较低位置向上照入，下方朝向光源的表面先受光，面部和物体的投影关系不同于常见上方照明。
- 用途：已有低位灯光、屏幕或反射光的表现，以及用户明确需要的异常明暗关系。
- 可用表达：已有低位光源向上照亮下颌与鼻部下侧，面部上方保留与入射方向一致的阴影，邻近衣料承接同一光源。
- 边界：保持光源依据，不默认增加手电筒、火盆或发光地面；不把底光自动写成惊恐表情或超自然事件。具体脸部图案仅用于能够辨认面部的取景。

## 补充光源与遮挡方法

### 23. 烛火照明

- 机制与表现：由场景中已采用的烛火提供局部暖光，靠近火焰的表面较亮，远处逐渐较暗；阴影与亮部受火焰位置、环境照明及反射影响。
- 用途：有来源依据的室内暖光、古代环境或有限照明下的局部层次。
- 可用表达：桌上既有烛火照亮人物靠火焰一侧的面颊和邻近桌面，室内远处较暗，衣料和木材在同一方向承接暖光。
- 边界：有烛台不代表烛火必须发光，白昼或灯具不发光的要求继续成立。连续影像只有在火焰确有变化时才描写相应轻微亮度变化，不让全画面无依据闪烁；不默认柔光、烟雾、古典服装或温柔眼神。

### 24. 斑驳光

- 机制与表现：日光被已有树叶或其他不规则遮挡物切割，在接收面上形成不连续的亮斑与阴影；斑块随遮挡形状、距离和表面朝向变化。
- 用途：呈现环境遮挡、自然纹理与局部层次，适用于已有林地、树荫等场景。
- 可用表达：日光穿过现有树叶间隙，在人物肩部和地面形成大小不一的亮斑，斑块随衣料和地面转折改变形状。
- 边界：区别于百叶窗的规则平行条纹，不把同一花纹平铺到所有物体。没有树木时不为该方法改成森林；斑块移动仅承接已有枝叶、人物或光源运动，不自行增加风。条目不默认清新或欢快情绪。

## 补充方向与光源表现

### 25. 正面光

- 机制与表现：光主要从摄影机所在的一侧照向主体，主体朝向镜头的表面较亮；具体阴影由光源高低、偏移、软硬和主体朝向决定。
- 用途：看清面部、表情、正面图案或产品信息。正面较均匀的照明可能减弱体积，需要时由相容的侧向差异或背景亮暗补充层次。
- 可用表达：主光从摄影机一侧照亮人物朝向镜头的面部，双眼与嘴部可辨，阴影随光源高度和脸部朝向成立，背景亮度保持原有空间层次。
- 边界：正面光不固定等同自然光、柔光或平整无阴影。蝴蝶光是前上方来光在特定脸部朝向下形成的图案，不要求所有正面光都出现蝶形鼻影，也不为了正面照明将背面取景改成正面。

### 26. 色彩照明

- 机制与表现：带颜色的光照到局部表面，与原有材质颜色、反射和其他光源共同形成可见结果。双色照明分别确定来源与覆盖区域，颜色交界及交叠由来光方向、遮挡和表面转折决定，不将同一配色无依据地平分所有表面。与对整幅画面的后期调色分别处理。
- 用途：区分已有空间或光源、组织人物与环境的颜色关系，或实现用户需要的风格化方向。
- 可用表达：已有彩色光源从人物一侧照入，使靠近光源的衣料与邻近墙面呈现相应色彩反射，另一侧保持既定主光色调，光源之间的覆盖与遮挡清楚。
- 边界：说明颜色、来源和覆盖区域，不用“电影感调色”代替设计。霓虹、色片、青橙对比只是可选实现或配色，不固定采用；保留用户指定的肤色与服装辨识要求，不自动把整幅画面涂成同一种颜色或增加招牌、灯带等道具。

### 27. 动态照明

- 机制与表现：照明的强弱、方向、覆盖区域或颜色随已有光源变化、主体运动或遮挡变化而变化，相关可见表面的受光、反射与投影相应承接。
- 用途：表现已有的运动、光源变化或叙事节奏，使照明与当前事件发生联系。
- 可用表达：人物沿既定路径经过已有遮挡时，侧面来光逐渐被挡住，面颊与衣料的亮区一起缩小；离开遮挡后重新承接同一方向的光，地面投影随位置连续变化。
- 边界：写清起始、变化原因、过程与结束状态或仍在持续的状态；不把任意波动当作动态感。日落、火光本身不代表快速变化，不为了术语增加闪电、火灾、飞溅火星或灯光闪烁；静态画面只写当前状态，视频变化不覆盖原有关键动作或时序。

### 28. 实用光源

- 机制与表现：场景中具有实际用途的灯具或发光物提供画内照明依据，例如已存在的台灯、壁灯、烛火或屏幕。可按取景让来源入镜，同时让附近人物与表面承接它的光。
- 用途：交代环境与光源位置，建立有来源依据的局部明暗及颜色关系。
- 可用表达：原有台灯在桌面与邻近人物身上形成局部亮区，灯罩影响照射范围，桌上物体投影与灯的位置一致，环境其他区域保持原有照明。
- 边界：与已有烛火照明等具体来源组合，不为每种灯具重复建条目。画内可见灯具不必是唯一光源，也不意味着实际拍摄只用了该灯；不能从画面断言幕后灯具配置。用户要求灯具不发光时继续保持，不为真实感强制增加灯具或让摄影灯入镜。

## 布光组合转译

把资料中的“方向 + 质地 + 效果”提炼为选择维度：先有场景光源依据，再决定来光方向、软硬与明暗组织，最后仅在目标需要时加入颜色、时间变化或空气与光学表现。情绪方向用于选择当前设计，不是必须遵循的灯位配方；已有光源条件也可能反过来决定可采用的方法。

组合名称不是完整 Prompt。必须说明光从哪里来、照亮哪些区域、如何作用于人物与材质；若需要整体调色，明确主次颜色及区域关系。同一光源可以产生逆光、轮廓与局部散射，多个名称不表示必须增加多个灯。

| 资料中的组合 | 转译为可观察结果 | 使用边界 |
|---|---|---|
| 侧光 + 柔光 + 电影感调色 | 侧向大面积光源使主体明暗过渡平缓，再依据用户目标协调衣料、墙面与背景的主次颜色，保留不同材质的辨识 | “电影感调色”必须具体化，不能代替颜色与空间关系；不固定为暖色或低反差 |
| 逆光 + 轮廓光 + 体积光／烟雾 | 后向来光沿人物外缘形成亮边；只有场景允许介质且需要可见光路时，才在指定空气区域表现散射 | 轮廓不需要雾也可成立，明确清透或无雾时只采用相容的受光与投影，烟雾不自动成为氛围必需项 |
| 硬光 + 色彩光 + 高对比 | 方向明确的光形成清楚阴影边缘，选定颜色只作用于对应受光区域，补光与背景亮度共同决定实际反差 | 硬光、颜色与反差分别控制，不固定为青橙、红蓝或霓虹；局部受光不等于全画面滤镜 |

## 场景组合用法

这里组合已定义的方法，不重复创建基础光影条目。组合只在用户的场景和时段允许时使用，既有颜色、材质与天气要求优先。

| 组合 | 有价值的条件与关系 | 可用表达与边界 |
|---|---|---|
| 低角度日光：晨曦暖光／落日余晖 | 根据既定清晨或傍晚，将自然光、侧逆光或轮廓光与局部暖色结合；低太阳角度影响投影方向与长度 | 光从地平线附近的既定方向照入，照亮朝阳表面与部分头发外缘，在地面形成与角度相容的较长投影。是否暖色、柔和或强烈按目标与天气选择；不把晨曦与落日当作两种新的布光，不默认镜头眩光、泛光或新增时间流逝 |
| 雨夜照明与湿表面反射：雨夜氛围光 | 在已确定的雨夜中结合实际光源、湿润表面的反射和必要的冷暖关系；不同材质分别处理 | 已有街灯或窗光在湿地面形成方向与位置相容的反射，人物受光与附近表面相互关联。雨滴与湿衣只在输入已有或授权范围内出现，不把所有地面改成镜面，不自动添加霓虹、雾、蓝色滤镜或忧郁情绪 |

## 常见名称归并

按下表定位已有方法，名称不同不构成新增理由。带时段、场所或情绪的称呼需要拆解条件，保留真正影响画面的差异。

| 补充资料中的称呼 | 采用已有条目或组合 |
|---|---|
| 阴阳脸 | 分割光；是面部明暗分区的俗称，不据名称赋予人物身份或心理 |
| 鬼光 | 底光；具体颜色与反差另由光源和场景决定，不固定为绿色 |
| 骷髅光 | 效果俗称；先观察眉弓、眼窝与颧骨的亮暗，再选择适合的方向、光的软硬与补光程度，不由名称断言固定灯位 |
| 牢笼光 | 已有规则结构的遮挡或投影；投影归入百叶窗光影，前景实体遮挡不自动成为投影光效 |
| 逆光剪影 | 按边缘轮廓光条目中的剪影条件处理；与轮廓亮边分别判断 |
| 红蓝对抗光 | 色彩照明的双色应用；明确两色来源、覆盖与交界，不据配色新增人物冲突 |
| 逆光／轮廓光、逆光轮廓光 | 边缘轮廓光；另外说明实际来光方向与是否形成剪影，不另建同义条目 |
| 低调光、体积光 | 对应同名条目；情绪描述按当前剧情选择 |
| 窗边柔光 | 窗户光 + 柔光；不把所有窗户光固定为柔光 |
| 月夜冷光 | 月光照明；冷色只是当前选择，不规定所有月光为蓝色 |
| 光束聚焦 | 聚光灯照射；需要且允许空气中可见路径时，再采用体积光 |
| 影棚柔光 | 柔光；按已有环境补充受控光源的方向和覆盖范围，不自动增加影棚背景或商业人像要求 |
| 晨曦暖光、落日余晖 | 低角度日光的两种时段应用，归入同一组合 |
| 烛火暖光、烛火阴影 | 烛火照明；暖色、反差与亮度变化按当前场景处理 |
| 林间斑驳光 | 斑驳光；林间是使用条件，不增加第二个相同方法 |
| 雨夜氛围光 | 雨夜照明与湿表面反射组合 |
| front lighting、正面光 | 正面光；照射方向与主体朝向分别说明 |
| colored lighting、色彩光 | 色彩照明；与整体调色区分 |
| dynamic lighting、动态光 | 动态照明；明确变化来源与相关表面的连续反馈 |
| practical lighting、visible source、实用光源 | 实用光源；来源可以入镜，但不强制所有场景新增可见灯具 |
| backlight、逆光，rim light、轮廓光 | 来光方向与外缘受光结果分别表达，归入现有轮廓及侧逆光方法，不因名称重复增加灯种 |
| soft light、diffused light，hard light、sharp shadows | 按柔光、硬光的实际阴影性质处理；清晰阴影是可见表现，不另建灯种 |
| volumetric lighting、god rays、dusty light | 体积光；“尘光”还需要已有或获授权的颗粒介质，不默认增加扬尘或烟雾 |
