# 电影布光设计

用于整场戏的光源组织、人物与空间塑形、材质响应、连续性和问题诊断。具体光效名称查阅[光影方法库](光影方法库.md)，作品做法查阅[导演光影转译](导演光影转译.md)。按任务读取相关部分，不将全部知识变成每条 Prompt 的必填参数。

## 从信息重点建立布光

先判断当前镜头中观众需要读清的主体、动作和空间关系，再建立主导光源、辅助照明与背景层次。需要隐藏的信息可以留在暗处；叙事重点也不必永远是全画面最亮的区域，可通过局部反差与位置得到强调。

### 光源动机与职责

光源动机说明画面中的照明为何成立，例如已有窗户、天空、灯具或屏幕。拍摄中的画外支持光可以增强或延续这个方向，不需要新增画内灯具；设计 Prompt 时写照明来源与可见结果，不从画面反推幕后用了几盏灯。

| 职责 | 决定什么 | 判断要点 |
|---|---|---|
| 主光 | 主要受光方向、主体塑形与重点 | 哪个来源主导人物及其邻近表面；多个来源不无依据地争夺主导 |
| 补光 | 暗侧的可读性与反差 | 可来自天空、环境反射或支持照明；补多少服从信息需求，不自动形成第二组强阴影 |
| 环境光 | 空间的基础照明与暗部颜色 | 与主光分别判断，不能因为环境可辨就把各表面照成同样亮 |
| 背景照明 | 建筑进深、背景重点与主体分离 | 不必须另设一盏灯；已有主光的覆盖、开口与遮挡也能完成 |
| 轮廓或局部强调 | 特定外缘、材质或物体的辨认 | 仅在当前取景需要时使用；人物分离可以靠背景亮暗，无须人人加亮边 |

这些是照明职责，不是固定的三点布光配方。同一光源可以承担数种职责，某些场景也可以只依靠一个主导来源。

### 加光、减光与限制覆盖

反差不足时先检查环境反光和光的覆盖，再决定是否增加照明。控光器材属于设计推理依据，不要求在画面中出现黑布、旗板或摄影灯。

| 方法 | 适用判断 | 转译为画面结果 |
|---|---|---|
| 反射补光 | 暗侧所需信息消失，而主光方向应保持 | 邻近表面的反射适度照亮暗侧，阴影仍保留方向和层次；反射颜色承接反射面的材质 |
| 负补光 | 环境反射把暗侧填得过亮、塑形变平 | 背光侧接受的环境反光较少，保持比亮侧更深的阴影，所需眼部或动作信息按目标保留 |
| 遮光与切光 | 主光溢到背景或次要区域，冲淡重点 | 主光集中作用于指定人物或区域，背景与外围保持各自的照明；亮区边界由光源、遮挡和接收面决定 |
| 利用光束边缘 | 光束中心造成局部热点，覆盖不合适 | 将目标放在光束边缘的渐变区域，控制热点与相邻表面的亮度差；不保证所有灯束都因此均匀 |
| 扩散或反射柔化 | 阴影边缘过硬，目标需要平缓塑形 | 扩大有效发光范围，使阴影过渡变缓；补光量仍独立决定明暗反差 |

负补光减少到达暗侧的光，不是把皮肤改黑或在后期涂一块黑色。限制覆盖也不等于在清透空气中生成可见光锥。

## 明暗层级与光源几何

### 分别控制三组亮度关系

- **人物亮侧与暗侧：** 决定面部和身体塑形，以及眼部、表情和动作可读性。
- **人物与背景：** 决定局部辨认。亮人物可置于较暗背景，暗人物也可借较亮背景呈现轮廓，不固定只有一种方向。
- **室内与开口或发光区域：** 决定窗口、灯具与室内是否同时保留信息，以及哪部分允许接近纯亮或纯暗。

先安排这些关系，再确定整体影调。整体调低曝光会同时压暗人物与背景，不能自动修复灯光覆盖过广的问题；整体抬亮也不能恢复已经丢失的高光细节。按目标决定哪些高光、深暗或剪影可以缺少细节，不把“亮暗部全部清楚”当作统一标准。

普通 Prompt 优先写相对关系。用户需要技术数值时，注明比较的是两灯照度、表面总受光还是线性亮度；这些口径不通用。线性亮度相差一挡约为两倍，最终调色后图像的像素值不直接代表该关系。例如，主光与补光照度为 2:1，只有在补光同等照到两侧、主光只作用于亮侧等条件下，亮暗面的总照度才为 3:1，不能无条件互换。

### 大小、距离与覆盖分别判断

阴影软硬主要取决于从主体看去的有效光源角尺寸，而非灯具功率或现实尺寸本身。大面积光源很远时仍可能形成较硬的光；扩散面或反射面只有实际成为有效发光范围时才参与判断。

近处光源在主体移动后更容易出现亮度差，改变距离还可能同时改变软硬与覆盖。小光源近似点光源且条件相容时，照度可按距离平方反比估算；大面积光源、聚光光束、反射光和远距离日光不能一律套用这个近似。不凭“靠窗”二字推定固定衰减或软硬，仍需看天空、直射光与开口条件。

## 空间布光

先找当前机位真正看见的前景、中景和远景，再安排局部受光、暗区与表面转折。分离可以依靠明暗、颜色、材质、遮挡或它们的组合，不必使用雾或全身轮廓灯。

- 前景遮挡可较暗，但是否保留人物或物体细节由剧情决定。
- 主体区域保持所需局部反差；附近墙柱的亮暗承接同一来源，不把亮区浮在人物身上。
- 远景建筑通过柱面转折、开口内部的深暗、台阶或台口厚度、局部受光和遮挡呈现进深。次要区域亮度可以降低，但不整片抹成灰白或黑底。
- 高反射墙面或白色服装可能夺取注意力，先控制其受光覆盖与相对亮度；材质和服装颜色属于保持范围时，不靠改色解决。

贴图感还可能涉及透视、几何、人物接触或背景运动。光影设计可补足一致的体积、遮挡与材质反馈，不声称增加阴影就已经完成建筑重建。

## 人物、材质与颜色

### 人物塑形服从朝向与表演

在可辨面部的取景中，按脸部朝向判断鼻影、眼窝、颧骨与下颌，再选主光方向和暗侧可读性。三分之二侧面中，照亮靠摄影机、可见面积较大的面颊属于宽侧照明；照亮远离摄影机、可见面积较小的面颊属于窄侧照明。二者是相对取景与朝向的塑形选择，不用于改变人物脸型。

眼神光应与可反射的光源位置和大小相容，不要求每只眼睛永远有同样光点，也不从光点数反推灯具数量。眼窝是否留暗由目标决定；需要读清眼神时，可调整相容的补光与覆盖，不能同时要求双眼完全隐没。

人物转头、俯身或经过遮挡后，面部图案和身体受光自然改变。保持灯位不等于冻结伦勃朗三角或亮暗分界；远景、背面或遮脸取景只处理能够观察到的身体与衣料层次。

### 按材质写光的响应

| 材质 | 需要辨别的表现 | 常见误用 |
|---|---|---|
| 皮肤 | 柔和体积与局部高光并存，额头、鼻部等响应随角度改变 | 为塑形增加油亮感，或抹平原有皮肤信息 |
| 木材与石材 | 表面粗糙度、纹理和几何转折；粗糙与抛光表面的反射不同 | 只写“木纹清楚”而各个柱面同样亮，把所有石材处理成镜面 |
| 金属 | 高光与环境反射往往主导外观，颜色和形状受周围环境影响 | 把金属本色当作唯一颜色，固定一条不随角度改变的白边 |
| 玻璃 | 透射、反射和折射共同影响可见内容，反光随机位变化 | 认为透明物体必定无反光，或无依据增加彩色折射 |
| 衣料 | 粗布、丝绸、薄纱的高光与透光不同，褶皱转折承接光向 | 所有衣料统一油亮，或让厚重衣物变得透明 |
| 湿表面 | 反光与观看角度、光源位置、粗糙度相容 | 把所有湿地面变成完整镜面，反射与实际来源脱离 |

镜面高光及反射可因摄影机或物体移动而改变，不能像固定贴纸一样粘在表面。接触阴影取决于实际接触、遮挡及光源范围，不把脚底画成固定黑圈，也不让布料或人物悬浮。

### 色温、白平衡与混合光

色温是光源特征之一，可见冷暖还受白平衡、其他光源与材质影响。同一光源在不同白平衡下可呈现不同颜色，色温数值也不能完整描述绿／洋红偏色或饱和彩光。

混合光分别说明主导来源、另一来源的方向和覆盖，以及交叠处的肤色与服装表现。冷窗光与暖灯光不必各占画面一半；用户需要肤色自然时避免整张脸被另一来源染色，用户已选风格化肤色时按其目标处理。材质的原有颜色与受彩光后的外观分别判断，不为保持原色而取消已授权彩光。

色彩照明改变受光表面，整体调色改变画面的色彩与明暗呈现；两者协调，但不能互相代替。低饱和也可保留人体与关键材质的细微颜色，不默认转换为黑白。

## 镜头与运动连续性

以场景中的窗户、开口、灯具或其他稳定坐标记录来光，而非只记录“屏幕左边”。机位改变后，固定光源在画面中的左右关系可能改变；正反打不为追求两张脸都从屏幕同一侧受光而无依据移动主光。

近景需要改善表情可读性时，可细化相容的反射与补光，但主导光向、影调和背景关系应承接全景，不能把同一场景重置成另一套来源。

一镜到底按既定路径检查人物在各区域的受光、投影、反射与遮挡。经过柱子或离开窗边时，照明可自然减弱或转移；没有自动曝光要求时，不默认全场亮度随人物移动而追着补偿。固定镜头的光源不变时，人物动作引起的变化仍应连续发生。

光源本身发生变化时，按既定节奏检查它同时影响的人物、建筑和地面；投影与反光跟随来源，不能只有人物脸部闪动。变化承接固定首尾帧、编辑母版或续接边界，不新增光源事件。

## 从症状诊断问题

把可见现象与原因推断分开。没有足够画面或过程证据时列出待区分的原因，不从一句“很假”直接断言某个渲染或生成后台故障。

| 现象 | 先区分什么 | 相应调整方向 |
|---|---|---|
| 远景泛白、像被遮住 | 空气介质、幕状眩光、高光扩散、整体黑位或曝光，还是材质本身 | 介质问题处理其范围，光学问题处理光源与镜头关系，影调问题调整局部亮暗；不以加雾掩盖 |
| 人物很平 | 主光过于正面、环境补光过多、背景亮度接近，还是面部细节被平滑 | 根据目标改变方向、减少暗侧反光或调整人物与背景关系；不直接统一加硬光 |
| 人物像贴上去 | 光向与颜色是否匹配，接触与遮挡是否成立，几何透视是否一致 | 修正有证据的受光、投影和材质交互；透视或几何问题不能仅靠调色解决 |
| 眼睛读不清 | 眉弓遮挡、方向、补光及取景是否允许看清 | 保持人物与拍法，按目标调整相容照明；不默认磨平阴影或换正面镜头 |
| 高光油亮、反射像贴纸 | 材质粗糙度、光源角尺寸及机位变化 | 根据材质和角度约束高光、反射的位置与形态，保留真实需要的亮部 |
| 运动时光影跳变 | 光源是否改变、主体是否穿过遮挡、机位或曝光是否变化 | 有原因的变化写清过程，无原因的变化承接前一状态；不把全部投影冻结 |

## 输出尺度

将所选方法压缩为当前镜头可见的来源、受光区域、亮暗关系、材质响应与必要的连续变化。简单任务只写相关结果，复杂场景可先写共用照明，再写人物或区域差异。数值与器材只在用户要求且有依据时保留；本文不扩展为灯具采购、现场供电或拍摄施工方案。
