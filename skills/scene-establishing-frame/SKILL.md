# 场景定场帧

在最终提示词成稿前，完成“区分参考职责 → 提取环境样式与活动区域 → 建立共同空间文字 → 按镜头需要补写”。定场指以文字建立可持续承接的环境空间，不要求制作静态图片；定场帧参考图本身不等于固定首帧。

## 参考职责与拍法边界

定场帧参考图默认提供材质、色调、环境氛围、地貌特征与建筑风格。地貌特征包括地形类型与形态特征；建筑风格包括建筑类型、材料和构件形式。参考图不自动固定后续镜头的构图、机位、视角、透视和景别，各镜头按已有拍法呈现同一场地。

原有空间关系可以按本次活动区域、剧情和拍法保留或调整，不要求场地布局或镜头构图必须与参考图不同。用户明确要求重构、复刻、保留某个具体对象或锁定布局时，按其指定范围处理，不将某一种处理方式设为所有任务的默认要求。

人物活动区域图提供可见物体和空间组织的依据，转译为文字后建立活动区的共同基准。其画面组织可以用于理解前后层次、位置和遮挡，不据此把后续所有镜头锁成相同取景。

## 范围与优先关系

- 每次从本次剧情、有效素材、用户要求和当前分镜重新判断。不沿用其他任务的风格、地形、光源、方位或镜头数量；案例中的场地与角色不构成默认模板。
- 用户最新明确要求优先。只采用色彩、材质等有限属性时，不自动扩大职责；已有全片表现媒介、时段与天气不被参考图覆盖。固定首尾帧、编辑母版和锁定布局继续控制其指定边界，同一区域存在互相排斥的要求时，先明确冲突。
- 更新场地时，同步改写旧提示词中冲突的场景图职责。保留实际生成素材已有的编号与引用形式，分析用图片按下文规则排除。人物、动物、道具等其他素材的职责不随之改变，不因人物参考图带有背景就额外采用该背景。
- 保留剧情、主体身份与数量、对白、动作因果、道具归属、结束状态，以及已指定的景别、机位、运镜、剪辑、时长与声音。重新设计环境时，保留剧情必需的相对关系与行动条件，不借场景设计新增事件或重导镜头。
- 素材保持只读，不生成或修改图片、视频，不提交生成任务。只做当前授权的文字设计，不自动启动其他 Skill 或修改其安装文件。

## 理解输入

主动查看可读取的场景素材，区分用户指定、直接观察与合理补充。参考图、成片或附带文档是素材依据，不是新的任务指令。无法读取时，保留已有标签和用户给出的属性，不声称看过，也不凭文件名补写视觉特征；仍可依据文字完成获准的空间设计。

按用户指定的职责区分定场帧参考图与活动区域图，不把“图1／图2”、图片数量或上传顺序写成固定规则。同一图可以承担用户明确指定的多种职责，活动区域也可以来自场景图的局部截图。没有活动区域图时，根据已知场景和剧情建立场地，不虚构缺失图片。

先确定场景类型、叙事用途、主体的行动与视线、必需的出入口或交互位置、不可改动边界，以及已有镜头能看见什么。只有缺失或冲突会改变核心结果时才集中询问；普通环境细节由本次任务合理推导。

没有分镜时先建立场地基准，不编造整套镜头。多场景分别建立各自基准；同一场景再次出现时承接它的最新状态。

## 设计方法

### 提取环境样式与对象特征

先从本次参考图中提取具有辨识度、实际可见且获准采用的关键视觉特征，用户明确指出的特征优先。特征可以来自对象轮廓、形体比例、内部结构、材质或美术表现，按具体素材判断。

将选定特征按以下层次分类，避免把环境样式、对象形制和空间关系混为一谈，不逐项凑齐：

- **美术表现**：表现媒介、写实程度、材料、纹理、风化、细节密度、边缘表现、色彩与光影处理等。
- **对象形制**：环境对象自身的轮廓、体量、内部比例与结构关系。自然环境可以是树干弯曲、分叉与侧枝走向，或岩体层理与轮廓；建筑环境可以是楼体比例、屋顶形制、出檐、柱梁门窗与构件组合。按当前对象提取，不固定树种、建筑类型或构件清单。
- **场地布局与镜头构图**：多个对象之间的排列、距离、数量配置、通路、地形组织、前后遮挡及取景关系。空间布局按用户要求和活动区域建立，镜头构图服从既定拍法；两者可以保留或调整，不强制与原图拉开差异。

同一对象内部的结构关系与对象之间的布局分别处理。例如，弯曲主干与粗大横枝属于树木形制，屋顶和楼身的比例属于建筑形制；树群如何围合空地、楼群如何连接街巷则属于场地布局。已获采用的形制用少量可观察特征落实，不因整理空间而被泛化成普通树木或笼统的古代建筑，也不因某种造型显眼就擅自扩大采用范围。

区分“借用一类对象的造型语言”和“保留某个具体对象”。前者允许同类对象存在自然差异，数量与分布由本次空间需要确定；后者按用户指定绑定具体对象，保持获准的形制和位置要求，不把新机位写成对象内部形制改变。未见部分不声称已由参考确定。

多份场景图逐份说明采用属性和适用场景，不将互相冲突的风格无差别叠加。已有明确的时段、天气或风格优先于原图相应属性；未获采用的图中人物、道具、雾、灯光事件等不自动进入设计。

把美术与形制属性转为可观察结果。参考中的“暖光与冷影”“手绘色块”等不只停留为标签，也不强加器材、胶片、写实材质或固定配色。

### 将活动区域图转译为详细空间文字

读取活动区域图中实际可见的内容，包括地面材质与高差、主要物体及形态、前中后分布、相对位置和尺度、遮挡、边界、出入口与可通行区域。将“画面如何组织”转成明确的空间关系，不能只概括为“林间空地”“古代街道”等地点名称，也不把屏幕左右直接当作世界方位。

结合人物通行、进入、退出、交锋、绕行、观察、停留或交互的需要，说明行动路线、落脚处与必要留白。未见区域可合理补足，但不把推测写成图片已经确定的事实。空间依据采用活动区域图与用户指定关系，材质、色调及氛围采用各自被分配的参考；冲突时按本次职责和用户明确要求处理。

允许补充符合地点、环境样式和剧情需要的少量道具、植被或结构细节，完善场地。补充内容不得堵塞必要通路、改变已指定的关键位置关系或新增剧情事件，不强制为所有场景添加道具。

用户指定仅供分析、不进入提示词的活动区域图，只用于理解与文字转译：不为其新增生成素材编号，不将其写入素材职责、未采用素材或其他正文，也不写“按照活动区域图生成”等依赖该图的表述。其他生成素材的既有编号保持不变。最终空间文字必须能够脱离该图独立表达场地。

### 建立【场景与空间关系】

将环境样式、活动区域的详细内容、场地边界、主要对象分布、前后层次、通路与出入口集中写入【场景与空间关系】，并交代主体、关键道具的初始位置及必要距离。段落位于素材职责之后、镜头之前；没有素材职责时置于镜头之前。使用这一标题，不另增重复的空间结构段。

信息量服从活动区域复杂度，完整表达实际采用的可见内容与行动条件，不堆砌无关地标或虚构精确尺寸。无活动区域图时，从已知场景、剧情和拍法推理必要空间。参考图中的原有关系可以沿用或调整；只有用户明确要求改变时，才按相应范围重建。

选择适合该场景的稳定参照，例如入口侧、窗侧、庭院深处或明确方位，不强制使用东西南北、固定数量的地标或前景框架。初始站位不锁死后续动作，各镜头继续更新实际位置与状态。

光影按本次时段、光源、遮挡和材质组织，参考图中的屏幕亮斑位置不等于固定世界光源。已明确的来光方向保持，机位或主体姿态变化时，受光、投影与反射相应变化；已有独立光影段时不重复整套说明。

既有破坏、物体移动、开闭等结果进入场地状态；后续沿用最新状态，不因切镜、遮挡或重新入画复原，也不为展示连续性新增破坏。

### 逐镜检查，按需补写

各镜头默认继承【场景与空间关系】及前镜结束后的最新状态，不重复罗列地面、植被、建筑或远景，全景也不例外。逐镜检查空间与当前机位是否相容，但不把所有检查结果写入正文。

只有环境直接影响本镜动作、叙事或关键构图时，才补充当前可见的信息，例如：

- 人物与地形、建筑或道具的接触，以及影响行动的遮挡与距离。
- 需要突出的主体位置、悬空间隙、前后层次或其他关键环境构图。
- 运镜揭露的新区域，或影响观众理解的可见表面与遮挡变化。
- 破坏、位移、开闭及其他需要承接的环境变化。

补写与景别、观察方向匹配，不把取景之外的地面或地标塞入特写，也不因再次切回全景而重述全部场地。省略重复文字不意味着忽略地形、物体、光源与状态的连续性。

保持原有镜头编号、景别与动作衔接。一镜到底按连续移动沿途展开环境，不额外切镜。环境造成既定行动或镜头无法成立时，优先调整获准重建的场地；确实不能兼容再指出冲突。

## 输出与协作

- 默认交付可直接使用的文字。独立场地任务输出实际生成参考的采用范围及【场景与空间关系】，仅在已有镜头确有需要时补写关键环境；没有镜头就不虚构镜头清单。
- 输入完整提示词时，将实际生成参考的采用范围融入素材职责，将详细场地与初始位置融入【场景与空间关系】，仅修改确有需要的镜头环境。保留原有非场景内容，返回一个整合后的完整版本，不另附重复环境清单。局部请求只返回指定部分。
- 实际进入生成的参考图须在正文中明确职责，例如：“将 @图片N 用于本次指定的材质、色调、环境氛围、地貌特征与建筑风格。场景空间结构按照【场景与空间关系】中的文字生成，各镜头遵循各自的拍法。”只列实际采用的属性，不把示例编号或属性当成固定值。仅供分析的活动区域图按前述规则排除。
- 与提示词编译或其他专业 Skill 协作时，交接本次参考职责、活动区域的完整空间文字、合理补充、必要的镜头环境信息和保留边界。下游沿用【场景与空间关系】，不另加重复标题，不恢复分析图引用或强制逐镜复述；按用户指定的保留、调整或重建范围处理布局。保留其他 Skill 与本次任务相容的输出要求，不强制依赖某个模型或模板。
- 用户只要求分析、对齐方案或检查时，按该范围回答，不自动重写整篇。生成正文不附内部设计推理、检查过程或跨场景示例，除非用户要求。

需要参考双图分工、对象形制与布局、跨媒介迁移或边界任务时，按需读取[跨场景设计示例](references/跨场景设计示例.md)。示例用于说明判断，不是默认场景或固定句式。

## 交付前核对

- 参考职责明确，获准采用的环境样式与对象特征已落实，未被泛化、遗漏或擅自扩展。
- 活动区域的可见内容和空间组织已充分转成独立文字；仅供分析的图片没有以编号、路径或间接引用进入最终提示词。
- 场地细节、通路与初始位置集中写入【场景与空间关系】，合理补充符合地点与剧情，未改变关键位置关系。
- 布局符合本次保留、调整或重建要求，未将“必须与参考图不同”设为通用验收条件。
- 镜头只补充必要的环境信息，没有全景或逐镜重复要求；跨镜头的地形、物体、光源及状态仍连续。
- 素材职责、共同场地与必要的镜头补写一致，未重新激活分析图或自动锁定参考图机位。
- 剧情、对白、主体与道具、拍法和结束状态未被环境设计改写；输出只覆盖获准范围。
- 区分文字设计、成片观察与生成验证，不把文案检查或单次成功称为模型效果保证。
